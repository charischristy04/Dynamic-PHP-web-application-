# Student Management System

A PHP and MySQL web application for managing student records with CRUD operations.

## Features
- Add new students
- View all students
- Edit student information
- Delete students
- Input validation
- Prepared statements for security

## Setup
1. Install XAMPP
2. Start Apache and MySQL
3. Import dynamic_project.sql in phpMyAdmin
4. Access: http://localhost/student-system/

## Technologies
- PHP
- MySQL
- HTML/CSS
